# 서식지 적합도 스코어카드 (Habitat Suitability Scorecard)

멸종위기 야생생물의 서식지 적합도를 분석하는 웹 앱입니다.

- 단일 HTML 파일(`index.html`)로 작성된 정적 웹 앱 (빌드 과정 없음)
- 기능: 서식지 적합도 계산, 사이트 비교, 공존 분석, 3D 디지털 트윈 시각화(Three.js), 전체 멸종위기종(282종) 디렉터리
- 데이터 출처: 국립생태원, GBIF, IUCN 등 공개 자료 기반

## 로컬에서 보기

빌드 과정이 없으므로 `index.html`을 브라우저로 바로 열거나, 아래처럼 간단한 로컬 서버로 띄우면 됩니다.

```bash
npx serve .
```
