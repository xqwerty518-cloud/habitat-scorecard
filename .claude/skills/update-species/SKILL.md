# 기존 종 데이터 수정

새 종 추가는 `add-species` 스킬. 이 스킬은 `js/data/species.js`에 이미 있는 항목을 고칠 때.

## 1. 근거 확인

- 바꿀 값의 출처를 찾는다 (국립생태원·환경부·국립생물자원관 > 국내 논문 > IUCN > 해외 논문). **근거 없이 수치를 바꾸지 않는다.** "점수가 이상해 보인다"는 이유만으로 factors를 맞추지 않는다.
- 등급(I급/II급)·국명은 최신 공식 「국가보호종 지정현황」 기준. 개정 연도를 확인한다 (예: 물범 2022년 II급→I급).
- 출처 링크와 바뀌는 값(전→후)을 사용자에게 먼저 요약해 보여준다.

## 2. 수정 범위

- 국명을 바꾸면 `LAND_SPECIES`/`MARINE_SPECIES`의 `name`과 `FULL_SPECIES_LIST`의 `n`을 **둘 다** 같은 글자로 바꾼다 (이름으로 연결됨).
- 등급을 바꾸면 `status` 문자열과 `FULL_SPECIES_LIST`의 `g`를 둘 다.
- `id`는 바꾸지 않는다. 3D 모양(`buildCreature`)과 저장된 공유 링크가 id를 쓴다.
- `factors`의 형식(`range`/`target`, `softness`, `tol`, `weight`)은 `add-species` 3단계 설명을 따른다. 한 번에 한 종씩.
- 282종 목록 전체를 개정판으로 바꾸는 큰 작업이면 바뀐 행만 diff로 정리해 사용자에게 먼저 확인받는다.

## 3. 검증

- `check-site` 스킬.
- 바꾼 종에 대해: 근거 서식지 조건으로 슬라이더를 옮기면 높은 점수(80점 이상), 명백히 맞지 않는 조건에서는 낮은 점수가 나오는지 내장 브라우저나 `page.evaluate(() => scoreSpecies(...))`로 확인.
- 다른 종의 점수가 함께 바뀌지 않았는지 (공용 기본값을 건드린 경우).
